# 로또

---

## 개요

간단한 로또 발매기를 구현한다.

**🛠 구현할 문제 기본 설명**

---

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 **그 부분부터 입력을 다시 받는다.**
    - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

## ✅검증사항

아래에 해당하는 입력이 들어오면 `IllegalArgumentException`을 발생시킨 후 종료시킨다.

---

**기본 입력 형식 검증 사항(validator)**

1. 당첨 번호 입력  &&  보너스 번호 && 금액
    - 숫자인가? ⇒ 문자와 같은 오입력 검증(+당첨 번호는 구분까지)
    - 숫자가 05와 같이 0으로 시작하는 형태인가?
    - 빈 or 공백 입력인가?
    - 오버플로우인가?


**로또 비즈니스 로직 검증 사항(domain)**

---

1. 금액
    - 1000의 배수인가?

2. 당첨 번호 && 보너스 번호
    - 1~45 사이의 정수인가?
    - 중복은 존재하지 않는가?
    - 당첨 번호의 경우 숫자가 정확히 6개인가?
    - 보너스 번호의 경우 당첨 번호와 중복되지 않는가?

```jsx
// 아래의 코드와 일맥상통하는 입력은 모두의 예외를 발생시킨다.

//validator
21474836453564542342454364553433422 ⇒ Overflow_error
00005 zero_start ⇒ error
문자 입력  ⇒ Format_error
" "  ⇒ blank or empty error

//domain
1004 ⇒ Thousand_Multi_error
1,2,3,4,5,46  Out_of_range ⇒ error
1,2,3,4,5,5  duplicate ⇒ error
LottoList = 1,2,3,4,5,6 bonusNumberInput = 6 ⇒ bonus & LottoList duplicate ⇒ error

```

‼️ **특수한 주의 사항**

---

1. 메서드는 하나의 기능만을 수행한다.
    - 메서드 들여쓰기가 “2”를 넘지 않도록 하고 return을 적극 활용한다.
2. esle-if, switch-case는 사용하지 않는다.
3. 예외를 던지고 프로그램을 종료하지 않고 다시 입력 받는다.
4. ENUM을 반드시 적용한다.


**상세 기능 구현 방향**
---

1.  **사용자 입출력 기능(view)**
    - 사용자에게 로또 구매 금액을 입력받으며 천의 단위 양수만 허용한다.
    - 사용자가 구매한 금액에 맞는 개수만큼 로또를 출력하고 당첨 번호를 입력받는다.
    - 사용자에게 보너스 번호를 입력받는다.
    - 구매한 로또들에 대한 총 당첨 내역과 수익률을 출력한다.

2.  **로또 구매 시스템 메인 기능(domain)**
    - 기본 로또 시스템을 만들어 로또를 생성하고 비즈니스 검증을 시행한다.
        - 유일한 번호인지, 중복은 없는지, 범위는 1~45인지 검증한다.
        - 각 단일 로또 한개를 비교한다.

    - 사용자가 입력한 금액에 맞게 로또를 구매하는 시스템을 만든다.
        - 기본 로또 시스템을 받아와 일급 컬렉션으로 구현한다.
        - 구매된 로또 목록을 복사하는 기능을 구현한다.
        - 당첨 번호와 그 로또 리스트를 비교하여 당첨 유무를 체크한다.

    - 로또 구매 금액을 포장하여 금액에 맞는 갯수를 생성할 수 있도록 한다.

    - 보너스 번호를 포장하여 당첨 번호와 함께 사용되도록 생성한다.

    - 당첨 번호를 관리한다.
        - 당첨 번호는 사용자에게 입력받은 6개의 숫자와 보너스 번호 1개로 이뤄진다.

    - 당첨 내역 결과를 관리한다.
        - 비교한 결과를 받아와서 결과를 전달하는 기능을 만든다.
        - 구매 금액을 받아오고 전체 수입금액 비율을 계산해서 수익률을 생성하고 반환한다.

3.  **컨트롤러를 통한 조율 및 기능 수행 요청(controller)**
    - 프로그램을 실행하고 총괄 조율을 담당한다.
    - 검증 유틸을 호출하여 기본 입력 형식 검증을 담당한다.
        - 구입 금액, 당첨 번호, 보너스 번호
    - 서비스에 입력 내역을 전달하여 로또 추첨 진행을 요청한다.
    - 결과를 안내받고 뷰어에 이를 전달할 수 있도록 한다.

4.  **로또 추첨 흐름 담당 서비스 기능(service)**
   - 구매 금액을 받아와 이에 맞게 랜덤 로또 번호 n개 묶음을 생성하도록 요청한다.
   - 생성된 로또 리스트와 입력받은 당첨 번호를 비교하도록 요청한다.
   - 결과를 받아와 저장하도록 요청한다.
   - 수익률을 계산하도록 요청한다.
   - 모두 끝난 결과를 컨트롤러에게 전달한다.

5. **로또 구현에 필요한 기본 유틸리티 기능(util)**
    - 기본 입출력 형식을 검증한다(금액, 당첨 번호, 보너스 번호)
    - 랜덤 로또 숫자를 추출하여 전달한다.

6. **전제 상수 관리 (enum)**
    - 로또 당첨 등수와 금액을 관리하는 이넘 클래스를 만든다.
    - 출력 안내문 상수 메시지를 따로 정의한다.
    - 예외 상수 메시지를 따로 정의한다.


📑**테스트 사항**
---

1. 기본 입력 형식 테스트
    - 당첨 번호 입력  &&  보너스 번호 && 구입 금액
        - 숫자인가? ⇒ 문자와 같은 오입력 테스트(+당첨 번호는 구분까지)
        - 숫자가 05와 같이 0으로 시작하는 형태 테스트.
        - 빈 or 공백 입력테스트.
        - 오버플로우테스트.

2. 메인 로또 수행 로직 테스트-
    - 로또 입력 생성 테스트(내부적으로 비즈니스 검증 사항 확인)
        - 구입 금액이 잘 생성되었는가?
            - 구입 금액이 천의 배수인가?
        - 로또 당첨 번호가 잘 생성되었는가?
            - 1~45인가?
            - 번호가 6개인가?
            - 번호 6개가 중복되진 않는가?
        - 보너스 번호가 잘 생성되었는가?
            - 1~45인가?
            - 당첨번호와 중복되지 않는가?
        - 금액에 따른 갯수만큼 로또 구매 리스트가 잘 생성되었는가?

    - 로또 비교 테스트
        - 우선 생성된 로또가 올바르게 복사되었는가?
        - 당첨 번호와 리스트를 비교하여 등수가 올바르게 저장되는가?
            - 예시로 4개가 겹칠시 4등이 올바르게 저장되는 테스트.
            - 5개가 겹치며 보너스 번호까지 일치함→ 2등 테스트.
            - 5개가 겹치지만, 보너스 번호는 일치하지 않음 → 3등 테스트.

    - 수익률 테스트
        - 당첨 결과에 따른 수익률이 올바르게 출력되는가?
